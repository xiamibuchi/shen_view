# 网格总览

网格总览占用主画布，用于在当前图片列表中找图。目录面板仍负责文件夹、章节和压缩包导航；底部胶片栏保持原显隐偏好，进入总览不会自动隐藏。

## 操作

- 顶部查看方式菜单 → 网格总览，或按 G 进入/返回。
- 单击卡片立即选择候选图片，不等待双击判定；双击或 Enter 打开候选并返回原来的单页、双页、长图或连续阅读。
- 页头返回按钮、G 或 Escape 返回阅读。未打开候选时保留原阅读位置、缩放和平移；Escape 优先关闭已打开的目录或菜单。
- 方向键按实际列数移动，PageUp/PageDown 按视口移动，Home/End 到首尾。输入框聚焦时保留文本编辑操作。
- 搜索仅过滤当前已索引列表的文件名/相对路径，显示匹配数和总数，序号仍沿用原列表顺序。
- 使用页头滑块、加减按钮或 Ctrl/Command + 滚轮调整缩略图大小；普通滚轮滚动网格。
- 底部胶片栏保持单击立即切图，网格候选同步到新的阅读图片。T 仍可手动切换胶片栏显隐。
- 信息面板显示候选图片的信息；旋转、翻转和打印先打开候选，再执行相应操作。失败的缩略图可点击重试。

## 与目录和阅读配合

网格复用当前范围与排序，不增加一次全盘扫描。普通目录关闭递归浏览时仍隐藏子文件夹行与紧凑章节栏，保留状态栏目录开关和目录面板空状态；按目录/章节浏览时，选择目录切换网格列表；连续平铺时，选择章节定位图片并保持平铺范围。内嵌包仍通过目录面板进入。

固定目录沿用宽度记忆，小窗口继续停靠，网格自动减列。浮动目录继续覆盖在主区上，选择成功后按原规则收起。目录开关位于底部状态栏的缩略图开关左侧，不随胶片栏隐藏；仅状态栏隐藏时，网格页头补充目录入口，右键菜单也保留入口。全屏、无边框和信息面板沿用原有布局规则。

进入总览暂停自动换图、自动滚动和隐藏主图的动图播放；返回后自动播放保持暂停，动图按原播放状态恢复。阅读视口保留在后台以保存进度。网格只构建可见行和少量缓冲，按卡片尺寸请求缩略图，动图使用静态首帧；暂停新增的阅读预载，保留已有的有界缓存。
