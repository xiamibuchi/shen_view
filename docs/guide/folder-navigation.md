# 文件夹与压缩包导航

## 浏览范围

设置 → 浏览通过递归和连续浏览两个开关决定图片范围。关闭递归时保留连续浏览偏好。

| 模式 | 图片列表 | 导航 |
| --- | --- | --- |
| 仅当前文件夹 | 当前目录直接图片 | 保留目录面板、当前位置及压缩包入口，隐藏普通子目录与紧凑章节栏 |
| 递归、按目录浏览 | 当前目录直接图片 | 目录树与同级入口切换子目录 |
| 递归、连续浏览 | 当前根目录及子目录图片 | 选择目录定位其中的图片，保持平铺范围 |

连续浏览按根目录图片、各子目录递归展开；排序只作用于每个目录组内部。
缩略图显示相对路径，压缩包保持独立入口，不展开进普通图片列表。
切换浏览模式保留当前图片；递归按目录浏览时，无直接图片的目录可自动进入首个可读子目录。
含压缩包但无图片的目录仍保留，完全没有可浏览内容的子目录不展示。

## 自动刷新

开启后监听当前浏览范围，合并文件变化后后台更新；失焦时累积变化，恢复焦点后再应用。
刷新保留用户最新选图，当前图片删除后回退到邻近位置。无关临时文件变化不触发重扫。
进入压缩包停止文件夹监听，返回后恢复。

关闭开关会停止监听和焦点触发重扫；手动重新加载或重新打开目录仍可读盘。
监听不可用时，恢复焦点会尝试重建监听并做有界刷新。
事件合并、过滤和重试参数以 [监听服务](../../apps/viewer/lib/src/application/folder_change_watcher.dart) 为准。

## 目录面板与压缩包

状态栏目录开关独立于胶片栏显隐；固定目录停靠左侧，取消固定后覆盖画布。
显隐、固定与宽度跨启动记忆，窄窗临时收窄不覆盖设定；空目录或未打开内容仍保留固定面板位置。
目录搜索保留匹配项祖先，不打开尚未进入的内嵌包。

显式打开的文件夹或包是导航根。从文件夹进入包时保留来源根和同级包入口；直接打开单包时以该包为根。
没有章节的包继续提供来源目录的同级入口，有章节时下拉框切到包内章节，外层同级包仍可从树中访问。
连续浏览平铺包内章节图片，内嵌包由用户主动进入。返回祖先恢复原选择。

上一包/下一包可手动使用；“包尾继续下一包”仅对从文件夹进入的同级包生效，首尾再次翻页才换包。
直接打开单包和内嵌包不参与自动换包。空包、取消或打开失败保留原内容，可重试。
包内只读与缓存生命周期见 [压缩包实现](../architecture/archives.md)。

目录宽度分隔条支持拖动和键盘调整，拖动中可取消、完成后可撤销；不显示宽度浮层或操作 tooltip。
视觉规则见 [设计规范](../design/spec.md)，目录与压缩包的交互样本见
[导航样本](../../apps/viewer/testdata/navigation/README.md)。

## 排序与扫描

普通目录和包内使用统一文件名排序，默认自然排序，可切为字符串比较。
排序项只显示规则名，示例放 tooltip；相同键用稳定身份兜底，包内不增加文件夹排序选项。

扫描先按扩展名识别，开启“扫描未知扩展名”后才读取未知文件头。
排序使用已有索引，切换排序不重新扫描磁盘；索引在后台执行并受深度、目录和条目上限约束。
实现见 [目录索引](../../apps/viewer/lib/src/application/folder_index_service.dart)，探针用途见
[验证说明](../development/validation.md#探针与性能)。
