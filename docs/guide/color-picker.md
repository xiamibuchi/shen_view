# 颜色拾取

顶部吸管进入取色，单击锁定一个像素，方向键微调采样位置；Esc、关闭按钮或再次触发入口退出。
网格中需先打开图片。拖动和缩放继续沿用当前查看方式，键位可在设置 → 快捷键中查询。

主复制按钮使用当前下拉格式，下方快捷复制不改变格式选择。格式和 YUV 数值约定见
[颜色模型](../../apps/viewer/lib/src/domain/picked_color.dart)，界面提示也会说明采样来源。
最近颜色跨图片、窗口和重启共享，重复拾取移到最前；只记颜色，不记文件和坐标。
切图或重新进入工具保留颜色，清除旧坐标；在新图单击后恢复方向键微调。

## 采样含义

- 结果取自当前已解码帧的一个像素，在缩放插值、背景合成和显示器变换之前读取。
- 普通结果为 8 位 sRGB 与 Alpha；透明像素不混入棋盘格，全透明像素的隐藏 RGB 可能已被解码器丢弃。
- 坐标从零开始，包含旋转、翻转和分块偏移；留白与双页间隙不产生取色。
- 静态图请求原分辨率，仍受资源预算约束；使用缩小结果时标记“预览采样”。
- SVG 按矢量来源栅格化；HDR 使用 SDR 映射或基础图，HEX 不代表未裁切的 HDR 浮点值。

## 播放与切图

取色期间暂挂动图、自动换图与自动滚动，退出后按原状态继续。
动图采样当前显示的合成帧，逐帧后清除旧帧锁定结果；最近色保留。
切图时丢弃旧图在途读取，避免异步结果回写。

共享记录的保存方式见 [实例模式](multi-instance.md#共享数据)，截图导出见
[视觉复核](../development/validation.md#视觉复核)。
