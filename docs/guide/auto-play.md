# 自动播放与动图

自动播放沿当前阅读列表推进，使用现有查看方式、排序、阅读方向和尺寸适配。
从当前位置开始；末尾按循环设置停止或回到开头，不自动扩展到其他目录或压缩包。

## 控制与计时

顶部按钮开始或暂停，开始后显示相邻的停止按钮；窄窗两者一起收进更多操作。
右上角状态区显示倒计时或滚动速度，齿轮可调整参数、循环和遇到动图的策略。
状态区可自动隐藏，停止后移除。

单页和双页按间隔换图；长图与连续阅读平滑滚动，各查看方式分别记忆参数。
长图无需滚动时按停留时间换图，整个连续阅读列表都能完整显示时停止推进。
设置 → 播放与画布快捷面板共享配置，修改参数不会自动开始播放。

图片实际显示后才开始计时，加载耗时不计入展示时间。暂停保留剩余间隔，停止清除计时但保留画面。
手动换图或改间隔后重新计时；主动缩放、拖动或解码失败时暂停，等待用户继续。
最小化、打开设置或操作菜单时挂起推进，恢复后不补跳图片。播放状态不跨启动恢复。

## 遇到动图

| 策略 | 自动换图行为 |
| --- | --- |
| 至少播放一遍 | 间隔已到且完整播放至少一遍后切换，不等待后续循环 |
| 按固定间隔切换 | 到时间切换 |
| 停留在动图 | 暂停自动换图，动图继续，等待用户操作 |

双页中所有可见动图满足策略后才换图。长图与连续阅读的滚动不因出现动图自动停止。
暂停或停止自动换图保留动图播放状态；主动暂停、逐帧或定位动图会暂停自动换图。
底部“动图”播放条负责暂停、逐帧、时间定位、倍速与循环，静态图不显示。

进入取色时暂挂播放并保留继续意图；进入网格后自动播放保持暂停。细节见
[颜色拾取](color-picker.md) 和 [网格总览](grid-overview.md)。
参数默认值、范围和存储形式以 [设置模型](../../apps/viewer/lib/src/domain/viewer_settings.dart) 为准。
