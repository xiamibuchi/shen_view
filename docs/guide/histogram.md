# 图片信息面板直方图

信息面板提供亮度和 RGB 通道叠加。横轴为 8 位显示值，纵轴为相对像素数量；
RGB 共用峰值，保留通道数量关系，曲线不修改统计结果。

统计基于有界 SDR 预览，透明像素按 Alpha 加权，完全透明像素忽略。
RAW 沿用显影，HDR 使用 SDR 映射，SVG 栅格化，动图固定统计首帧。
它用于观察预览分布，不代表原始 HDR 光度或全分辨率精确计数。

仅面板打开时计算，切图和关闭面板取消旧请求。失败可重试，不影响主图与基础信息。
计算与采样参数见 [实现](../../apps/viewer/lib/src/application/image_histogram.dart)，
截图导出见 [视觉复核](../development/validation.md#视觉复核)。
