# 打开、窗口与文件操作

## 打开与最近记录

打开图片、文件夹或普通压缩包后，可从右键菜单的“最近打开”再次访问。
欢迎页提供搜索、移除和清空；移除记录不删除源文件。失效路径保留到用户重试或主动移除。
同一目录内翻页不会逐张新增最近记录，重复打开同一路径会移到最前。

设置 → 通用可关闭记录、调整保留数量或让新窗口显示最近列表。
关闭记录会停止更新最近列表和启动位置，并停止自动恢复，已有列表保留。
清空同时移除启动位置，保留各路径的阅读偏好和进度。密码包及临时解包路径不进入列表。

启动时显式指定的路径优先打开；无路径时依次判断是否显示最近列表、是否允许恢复上次内容。
欢迎页打开期间暂停自动播放，可返回当前图片继续浏览。
独立窗口的启动方式见 [实例模式](multi-instance.md)。

## 全屏与无边框

全屏只改变窗口占屏状态，保留原有面板布局。
无边框独立于全屏，可在窗口化和全屏时启用，临时使用悬浮顶部栏并隐藏其他面板。
鼠标靠近顶部显示工具栏；退出后恢复目录、信息和胶片栏等原有状态，不覆盖普通布局偏好。
重新启动使用普通布局，窗口状态切换不重置图片位置和播放计时。

顶部提供无边框入口，右键菜单提供全屏切换。实际键位与改键入口见
[键盘与焦点](zoom-and-view-modes.md#键盘与焦点)。

## 窗口记忆

置顶偏好跨启动保留。大小和位置只记录普通窗口，最大化、最小化和全屏的临时尺寸不写回。
新窗口采用最近一次实际调整的记录；仅启动、聚焦或关闭未调整窗口不会覆盖记录。
显示器断开后回到可达工作区，已有窗口不随其他窗口移动。

关闭窗口时停止推进、保存阅读状态并等待在途写入；保存失败或超时仍允许关闭。
存储事务见 [共享数据](multi-instance.md#共享数据)，尺寸与位置计算见
[窗口控制器](../../apps/viewer/lib/src/application/window_placement_controller.dart)。

## 文件与打印

右键菜单提供复制、删除、保存副本、重命名及定位。压缩包内容只读，定位指向最外原包，
打印和另存为仍可使用。旋转、翻转和缩放只改变显示，不写回原文件。

“用其他程序打开”按当前图片格式列出系统关联程序，也可选择其他程序。普通图片直接打开原文件；
压缩包内图片先保存到用户指定的位置，再打开副本，编辑结果不会写回压缩包。取消保存不会启动外部程序。
开启文件夹自动刷新时，外部保存后返回查看器会按现有刷新规则更新图片。

打印先打开应用内预览，选择打印机、方向、纸张、页边距及适应方式，
再通过 printing 交给平台服务。当前不调用 Windows Photos 或系统文件关联打印。
