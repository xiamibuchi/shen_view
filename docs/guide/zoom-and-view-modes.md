# 查看方式、缩放与阅读

## 查看方式与尺寸适配

查看方式决定内容如何组织，尺寸适配决定初始大小，两者独立组合。

| 查看方式 | 适配对象 |
| --- | --- |
| 单页 | 当前图片 |
| 双页 | 整个跨页组合，两张按同一源像素比例缩放 |
| 长图 | 当前图片，极长静态图按需切片 |
| 连续阅读 | 当前阅读页作为适配锚点，随后保持整条画布比例 |

适应窗口完整容纳对象；适应宽度从顶部开始；适应高度从左侧开始；实际大小按源像素 100% 显示。
连续阅读不会把整本列表缩成一屏。统一页面宽高时，100% 使用第一页作为稳定阅读基准，
关闭后按共同源像素比例排版，各页保持宽高比。

状态栏百分比包含尺寸适配基线和手动缩放；内部矩阵为 1 不一定是源像素 100%。
缩放中心可选鼠标或视口中心，换图保持比例与保持位置是独立偏好。
各路径恢复查看方式、适配与阅读位置；显式打开某张图优先定位该图。
旋转、翻转和手动缩放不跨启动保存，密码包不持久化内部阅读进度。

## 缩放与边界

内容小于视口时居中，只在实际溢出的方向允许平移。每次拖动、缩放、惯性和尺寸变化都重新夹紧边界，
触边不积累隐藏位移，反向拖动立即生效。图片或窗口尺寸变化用视口中心的归一化锚点恢复位置。

同一模式中的缩放和平移使用共享视口，不改变图片布局尺寸；连续阅读变换整条画布。
切换模式保留当前原图，返回已看过的模式时恢复其位置；异步尺寸补齐不能让阅读内容跳动。
重复选择当前页或适配方式不重置已经就位的视图，升级解码精度期间保留已显示画面。

边界与变换实现见 [共享视口](../../apps/viewer/lib/src/presentation/zoomable_viewport.dart)，
连续阅读布局见 [连续阅读视口](../../apps/viewer/lib/src/presentation/comic_strip_viewport.dart)。

## 翻页与双页规则

单页和双页的持续滚轮输入会按频率限制连续翻页，停止后不排队补翻；
可在设置 → 操作切换为滚轮缩放或反转翻页方向。方向键和侧边按钮可长按连续切换，失焦或松开停止。
长图和连续阅读用方向键平滑滚动；长图触底后再次按向下键才换图，连续阅读边界只停止。

双页按整屏推进。封面可独占，宽图可独占或对静态 SDR 图片按中线拆分；
启用拆分后，尺寸未知、动图与原生 HDR 等不能拆分的宽图仍整张独占。拆分不改变文件和页码。
Shift 加左右键按一张原图步进并从目标图重新配对，之后继续整屏推进。

左右阅读方向只调整跨页的左右先后，不反转文件排序或键盘前后命令。
触屏横滑在适应窗口且没有内容溢出时按阅读方向翻屏；放大后的拖动只平移，捏合不触发翻页。
Ctrl 加滚轮按所选缩放中心缩放。普通触摸板平移保留直接操作。

连续阅读支持纵向、横向从左到右和从右到左；切换排列方向保持当前页及页内位置。
可见范围附近才创建页面，当前页动图播放，其余可见动图停在首帧；预载见
[资源管理](../architecture/resources.md)。具体默认值和阈值以
[设置模型](../../apps/viewer/lib/src/domain/viewer_settings.dart) 为准。

## 键盘与焦点

完整键位和当前自定义以设置 → 快捷键为准，菜单与 tooltip 使用同一绑定。
可按功能或键位搜索，点击录入区域后再按组合键；保存立即生效，各平台分别记忆。
冲突或系统保留键会被拦截。恢复本页默认只恢复当前平台，“恢复所有设置”同时清除各平台自定义。

输入框优先处理文字编辑；目录、网格和播放条保留自身的局部导航。
网格的文件操作针对候选项，取色期间复制命令复制颜色；压缩包内遵循只读规则。
搜索命令优先定位当前目录或网格搜索，只有阅读画布时打开网格搜索。
Esc 先处理弹窗、编辑或局部工具，再逐层退出网格、播放、浮层、信息面板和沉浸窗口状态。

默认绑定与命令范围见 [快捷键模型](../../apps/viewer/lib/src/domain/viewer_shortcuts.dart)，
焦点路由见 [快捷键处理](../../apps/viewer/lib/src/presentation/viewer_shortcuts.dart)。
