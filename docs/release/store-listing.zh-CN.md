# 神羊看图 · ShenView 应用商店文案

以下为上架用文案草稿。仅在对应发布包完成功能验收后使用；当前尚未上架。

### 应用名称

神羊看图 · ShenView

### 副标题

本地看图，文件夹浏览与漫画阅读

### 简短介绍

用网格、双页与连续阅读浏览本地图片和漫画，控制动图播放，并在兼容条件下查看 HDR 内容。

### 完整介绍

**把目光，留给图片。**

神羊看图（ShenView）是一款用于浏览本地图片的桌面应用。可以打开照片、浏览文件夹，或阅读压缩包里的漫画。

**从一张图，到整个文件夹**

通过目录面板切换文件夹，用网格总览寻找图片，再通过底部胶片栏浏览相邻图片。支持递归浏览子文件夹与自然排序。

**选择查看方式**

单页、双页、长图和连续阅读随时切换。适应窗口、适应宽度或按实际大小查看，也可以开启自动播放，按设定间隔换图或自动滚动。

**压缩包里的图片，也能直接看**

支持浏览 ZIP、CBZ、RAR、CBR 中的图片，无需事先手动解压。配合目录导航与漫画阅读方式，接着上一页继续看。

**控制动图播放**

暂停动图、逐帧查看、定位时间或调节倍速。

**查看图片细节**

可以放大图片、拾取颜色或查看图片信息。支持多种常见及扩展图片格式。图片、解码方式和显示设备均兼容时，可查看 HDR 内容；不满足条件时自动使用 SDR 显示。

**按自己的习惯看图**

选择浅色或深色主题，使用全屏或无边框查看，让界面适应你的阅读环境。
