### Highlights

- Browse local images and folders with recursive navigation, natural sorting, a grid overview and a thumbnail filmstrip.
- Read in single-page, two-page, long-image and continuous modes, including images inside ZIP, CBZ, RAR and CBR archives.
- Control animation playback frame by frame, inspect image information, pick colors and switch between light and dark themes.

### Fixes

- Fixed crashes when reopening files in single-instance mode (#10).
- Fixed PSD, AVIF and JPEG XL display failures on clean Windows 10 systems (#12).
- Fixed insufficient-resource errors when decoding some Nikon RAW main images (#21).
