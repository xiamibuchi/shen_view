# 界面设计规范

ShenView 使用 Fluent-inspired 的桌面界面，支持浅色、深色和跟随系统，默认深色。
Windows 与 macOS 共用视觉规则，窗口行为按平台适配；当前没有 Linux runner。
功能行为见 [使用说明](../README.md)，本页维护视觉、布局和控件约束。

## 主题与语义令牌

主题变化即时生效，不重新索引、不重开图片，不改变阅读会话、缩放、平移和面板状态。
图片本身不套主题滤镜，也不从图片像素提取界面颜色。

业务页面读取 ViewerThemeTokens，共享样式使用 AppTextStyles、AppControlStyles 和 AppDecorations。
颜色与几何分别由 theme/app_theme.dart 和 theme/app_tokens.dart 维护，数值以源码为准，
不在文档中复制一套色值表。

令牌定义见 [app_tokens.dart](../../apps/viewer/lib/src/presentation/theme/app_tokens.dart)。
外壳、图片视口、停靠导航和浮层使用各自的语义表面；图片内容不套用界面颜色。

普通文字与背景达到 4.5:1 对比度。主按钮白字、选中文字和错误正文在各组合状态下均需检查，
填充色、文字色与焦点提示分别定义。选中、警告、错误同时有文字、图标或边界反馈。

## 间距、字体与图标

- 使用 4 px 基础网格，常用间距为 4、8、12、16、24、32 px。
- 控件、菜单项、缩略图圆角 4 px；独立面板、菜单、对话框和卡片圆角 8 px。画布、普通工具栏和底部栏保持直边。
- 普通点击目标至少 32 × 32 px，主要操作至少 40 × 40 px；不通过缩小命中区适配窄窗。
- 正文 14 px、辅助文字 12 px、页面标题 20 至 24 px，字号和行高统一来自 AppTextStyles。
- Windows 首选 Segoe UI Variable / Segoe UI，中文回退 Microsoft YaHei UI；Apple 使用系统 UI 字体和 PingFang SC。系统字体不随应用打包。
- 应用动作图标使用 Fluent UI System Icons Regular，常用 18 至 20 px、紧凑 16 px。同一动作共用 glyph，窗口控制遵循平台行为。
- 图标按钮提供 tooltip、语义名称、禁用和键盘状态。长文件名与路径允许省略，提供完整 tooltip 或复制方式。

品牌与信息 UI 图标使用预生成多倍率 PNG，生成方式见 [SVG 实现](../architecture/svg-rendering.md)。
Material Icons 字体仍供 Flutter 默认控件使用，不能因业务图标已迁移就直接移除字体。

## 表面与材质

普通工具栏、固定目录、底部状态栏使用 navigationSurface，以 1 px navigationBorder 分隔，
分隔线以前景绘制，不挤占控件尺寸。底部状态栏贴齐左、右、下边缘，无外间距和向上阴影。

工具栏模式仅改变顶部栏的定位。悬浮顶部栏覆盖图片，底部胶片栏仍停靠在画布下方。
顶部应用内模糊 sigma 14，覆盖目录 sigma 16；严格裁剪，覆盖目录避开顶部栏，交界不叠两层材质。
深色顶部/目录不透明度分别为 76% / 84%，浅色为 82% / 88%。

系统关闭透明效果、提高对比度、进入节能状态或图形能力不足时回退纯色。
Windows 不启用整窗 DWM Acrylic；macOS 使用应用内材质及系统偏好接线，不宣称原生 Vibrancy。
macOS 原生材质、字体和窗口行为仍需实机验收。

信息面板为独立卡片，四周留 8 至 12 px、内部 16 px。空间不足时覆盖在主区，
顶部与底部避让工具栏和状态栏；缩略图跟随图片列收窄。

## 控件与组合状态

交互组件定义默认、悬停、按下、聚焦、禁用；按需增加选中、加载和错误。
禁用优先于悬停、按下和聚焦，禁用开关仍要区分开启和关闭。

- 普通按钮使用 controlFill 与中性状态底色，聚焦将 textPrimary 以 10% 混入 controlFill；强调和危险按钮分别在自身填充上暗化 6% / 12% / 20%，对应悬停、聚焦、按下。普通、图标及窗口按钮通过底色表示聚焦，不叠加焦点描边。
- 输入框、选择框保留 1 px 中性边框，编辑、展开或聚焦时整圈改为 accentStrong，错误使用 danger；不叠加底部强调线或发光阴影，聚焦不改变尺寸。
- 卡片等需要轮廓提示的组件使用共享中性焦点环。选中、悬停、按下、聚焦组合后仍保留选中含义。
- AppTextAction 用于欢迎页开始操作、通知及设置里的次要文字操作；与正文左对齐，使用变色、下划线和手形指针反馈。
- 控件默认高 36 px，突出操作高 40 px。随文字缩放增高，至少保留上下共 12 px 留白，按 4 px 步长取整。
- 弹窗操作按钮等宽等高，最小宽 104 px、间距 8 px，右对齐；空间不足时纵向排列。删除、密码与恢复默认共用此布局。
- 开关占位 40 × 36 px、轨道约 39 × 24 px，保留点击、拖动、键盘和语义行为；选中悬停和按下仍保持强调填充。

### 输入与搜索

AppInput 管理内部或外部 controller，输入、占位与中文组字共享字体、行高及 strut。
标签关联输入框语义，图标和内边缘也可点入编辑；禁用时恢复箭头，不参与 Tab 遍历。

清空功能预留 32 px 槽位，非空时显示，不挤动正文；清空只发送一次 onChanged('') 并保留编辑焦点。
只读及禁用输入不显示清空。搜索与密码不加任意字符上限，文件名编辑保留 240 字符限制。

输入框与选择框各占一个 Tab 停靠点，默认高 36 px，标准密度保证文字与外部图标垂直居中。
文字选择使用 24% accent，光标与拖动柄使用 accentStrong。

Windows 仅在可编辑文本聚焦时恢复主窗口及 Flutter 子窗口的 IME 上下文，
画布聚焦时解除关联，使快捷键直接响应；只读字段不启用 IME，不改系统输入法模式。
原生回归要覆盖反复进入搜索、中文输入、回到画布和快捷键恢复。

### 菜单与选择器

Select、右键及子菜单、排序和播放菜单共用 14 px 常规字重、4 px 容器留白、中性边框及分主题轻阴影。
选中通过强调文字和勾选表示，底色普通 12%、悬停或聚焦 18%、按下 24%。
菜单行聚焦仅改变背景，禁用项不显示交互底色。键盘打开 Select 先聚焦当前有效选项，
方向键跳过禁用项，关闭后恢复触发控件焦点。

菜单只在存在快捷键或勾选时预留尾槽；长文字单行省略，语义保留全文。
设置选择器默认同控件宽，必要时扩至最长选项，最多 360 px；更长内容省略并提供 tooltip。

右键顶部操作固定四槽：复制、删除、打印、另存为，图标在上、文字和快捷键在下。
没有有效图片时保留槽位并禁用。子菜单使用短暂关闭等待及安全三角，支持斜向移动。
排序项只显示规则名，顺序示例放 tooltip。

### 数字字段与打印预览

数字输入执行整次编辑校验，非法粘贴保留原值，允许暂时清空重输。
单位、范围与精度就近提示，非法值明确报错并禁用保存；不得显示一个值却静默按另一个值处理。
默认值与合法范围由 [设置模型](../../apps/viewer/lib/src/domain/viewer_settings.dart) 维护。
AppNumberInputFormatter 拒绝科学计数法、符号、混入文字和超出精度的编辑，小数字段接受逗号并归一为小数点。
输入法组字期间不改写，提交非法组字时恢复上次合法编辑；空串、小数点和尾随小数点允许暂存。
打印页边距与压缩包内存字段按各自模型限定范围、单位及精度，输入提示与保存校验保持一致。

打印标题与文件名分两行，关闭按钮靠右。内容宽至少 720 px 时左预览、右侧 320 px 设置；
窄时上预览下设置，预览最多高 240 px 且不超过主体 40%。设置独立滚动，底部操作组固定。
页边距错误保留有效预览并禁用打印，提交时防止重复任务，纸张本身始终白色。

## 响应式布局

原生最小窗口 600 × 460 逻辑像素。命令栏和状态栏按内容实测宽度折叠，
不按固定窗口断点或缩小控件处理。收起立即生效，展开需要额外 24 px 滞回，避免阈值抖动。

顶部命令栏保留居中文件名，按排序文字、置顶、末尾命令的顺序折叠；
命令收进更多操作仍保留图标、快捷键和名称。自动播放与停止相邻且一起折叠。

底部状态栏左侧目录/胶片栏开关及文件信息、中间信息开关、右侧缩放与全屏。
左右两段等分可用空间，中间开关保持居中。依次将缩放工具移入浮层、隐藏文件信息、
把尺寸适配入口移入同一浮层，极窄时最后收起全屏。

缩放浮层开在触发按钮上方并右对齐；窗口缩放、移动、失焦、全屏切换、打开右键菜单或 Esc 时关闭。
目录的固定、宽度记忆和拖动规则见 [目录导航](../guide/folder-navigation.md)。
无边框与全屏的布局恢复见 [窗口操作](../guide/window-and-file-operations.md)。

## 设置与参考页面

设置分为通用、外观、浏览、查看与阅读、操作、播放、压缩包、图像与 HDR、快捷键、关于，
快捷键与关于属于参考分组。分类独立保存滚动位置，搜索支持中文组字，清空恢复正常分类内容。

页头恢复默认只影响当前分类，确认时说明范围；无变化时禁用。
快捷键可修改，页头可恢复当前平台键位；关于没有可修改项，不显示页级恢复。
侧栏底部恢复所有设置覆盖所有分类和各平台快捷键、目录宽度，保留阅读进度及最近记录。

外观和浏览的目录显隐、固定共用偏好；固定面板在无章节或未打开内容时保留位置和空状态。
压缩包设置入口嵌入说明文字，用强调色区分，不增加按下底色。

快捷键的可编辑与固定项共用键帽尺寸及字重，轻量区分；录入由点击录入区域开始，
一次录入或失焦后停止。清除与单项恢复为左对齐文字操作，保存/取消位于底部。
操作和作用范围见 [键盘与焦点](../guide/zoom-and-view-modes.md#键盘与焦点)。

关于页身份、版本与介绍保持完整分组。底部开源许可为无底色文字入口，
列表按组件聚合、搜索并展示完整不同许可文本，排除仅开发依赖；收集规则见 [许可维护](../release/open-source-licenses.md)。

## 动效与通知

面板和工具栏过渡通常 150 至 200 ms，使用 easeOutCubic；缩略图状态 100 至 150 ms。
系统减少动态效果时关闭非必要动画或缩为 0 至 50 ms。加载不遮挡已经显示的图片，
拖放提供可见提示。

通知使用 AppNotificationHost / AppNotificationController，右上角顶部留 60 px、右侧 16 px，
最大宽 420 px，窄窗按可用宽度收缩。采用 elevated 表面、5% 状态底色、65% 中性边框和 8 px 圆角，
图标跟随首行文字中心与文字缩放，关闭命中区 32 × 32 px。

success、info、warning、error 分别使用成功、强调、警告、危险语义色及 Fluent 图标。
全部可关闭，success / info 4 秒、warning 6 秒自动消失，error 保留到手动关闭。
操作不代替关闭，多条可滚动，长错误可换行及选择复制；空包、打开、文件操作和打印失败使用 error。
通知显示时沿用 HDR 浮层的 SDR 回退，关闭后恢复，销毁时清理计时器。

## 视觉验收

实际渲染深浅主题、受限窗口、100% / 125% / 150% 文字及关键空状态，
检查对齐、最小间距、截断、焦点和状态组合。测试通过不能替代看图，
模拟 DPI 不能替代原生屏幕与 HDR 验收。执行入口见 [验证说明](../development/validation.md)。

主题 demo 通过 SHENVIEW_THEME_DEMO=true 或 --theme-demo 启动，只用于视觉评审，
真实文件索引、解码、窗口与打印以 ViewerPage 为准。
