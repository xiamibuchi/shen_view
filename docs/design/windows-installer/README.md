# Windows EXE 安装器设计

EXE 安装器使用 Inno Setup 7。构建、实现、故障恢复和发布前待验收项集中维护在
[安装器说明](../../../packaging/windows/inno/README.md)，渠道与数据位置见
[Windows 分发](../../release/distribution.md)。本页只维护界面与交互约束。

## 布局

安装与重装使用 640×480 DIP，格式弹窗 560×460 DIP，卸载使用 520×380 DIP。
同一流程的确认、进度和完成状态保持尺寸；卸载长路径与异常信息按换行增加必要高度。
工作区不足时压缩留白，保留字体和控件点击尺寸，主窗口和格式弹窗最低采用 432 DIP 高度。
主页面完整展示内容，不显示步骤指示和滚动条，底栏固定，只保留当前操作。

从上到下排列品牌与语言、安装位置、快捷方式、打开方式摘要和底部操作。
安装位置是主要区域，只保留一个路径输入框及浏览按钮，实际补全路径和错误放在其下方。
首装不显示重复介绍，空间正常时不显示容量信息。卸载只显示当前位置文字，不提供路径编辑。

桌面与开始菜单快捷方式直接展示；首装默认只选开始菜单，更新读取现状。
打开方式只显示图片、压缩包的数量摘要和“自定义…”文字操作，不添加资源管理器右键入口。
格式弹窗用页签切换图片与压缩包，支持全选、清空和单项选择；确定提交，取消丢弃临时修改。
弹窗说明只添加“打开方式”候选、不改变默认应用，格式清单从应用导出。

浅深色共用结构并跟随系统。标题 24 px、正文 14 px、辅助文字 12 px；
Windows 使用 Segoe UI / Microsoft YaHei UI。控件圆角 4 px、容器圆角 8 px，间距采用 4 px 网格。
主按钮 104×40 DIP，按钮间隔 8 DIP。使用品牌强调色，错误同时提供文字和语义图标。
不使用装饰卡片、巨型版本号、玻璃效果和入场动画。

隐藏系统标题栏，保留 DWM 阴影与圆角；品牌和空白区域可拖动。
按钮保留键盘、焦点和模态行为，区分悬停、按下、焦点及禁用状态；文字操作保留原生按钮语义。
格式页签使用选中下划线，路径错误同时反馈文字及边框，完成页使用成功图标。
进度与完成内容居中；按实际字形测量启动复选框的宽度及垂直中心，检查路径文字上下留白。

## 流程与反馈

| 场景 | 确认内容 | 主操作 |
| --- | --- | --- |
| 首装 | 可选安装位置、快捷方式与打开方式 | 安装 |
| 更新 | 当前与本次版本，说明覆盖应用文件并保留设置 | 更新 |
| 同版本 | 说明重新部署应用文件并保留设置 | 重新安装 |
| 更旧版本 | 显示两个版本，阻止覆盖 | 引导使用更新安装包 |
| 迁移 | 明确展示新旧位置，确认后执行 | 更新或重新安装 |
| 卸载 | 当前安装位置、移除项与保留项 | 卸载 |

路径错误在字段下说明并禁用主按钮。无关非空目录不得接管，新旧位置不得相互包含。
UAC 在点击主操作后触发，取消后保留选择。应用占用时提示正常关闭并等待退出，未退出则允许重试。

执行期间的“完成后关闭”、Alt+F4 和关闭按钮均最小化窗口，继续完成操作或恢复。
成功后正常退出，失败或有警告时显示结果。恢复期间显示恢复状态，不沿用安装百分比。
失败页区分未修改、已恢复、恢复未完成，提供原因、日志和关闭入口。
重试先返回保留选择的确认页；恢复未完成时隐藏重试，提供恢复副本入口。

完成页只保留完成按钮，安装或更新后可选择正常权限启动应用、打开 Windows 默认应用设置。
卸载默认保留用户数据；完全卸载需再次展示清理位置和范围并确认，具体归属边界见安装器说明。

## 语言与验收

语言沿用 system / zh / en，右上角切换后立即更新页面与弹窗并保留选择。
优先读取原用户最新应用语言，再读安装偏好，最后跟随系统。
安装或更新成功后合并回应用设置；取消、失败和卸载不覆盖既有偏好。
system 保存原值；不支持的系统语言回退英文，提权后不误读另一管理员的设置。

实际检查中英文、浅深色、长路径与错误换行、键盘焦点和中文输入。
原生验收覆盖 100%、125%、150%、200% DPI、独立文字缩放、跨显示器与读屏；
确认正文、格式弹窗和结果页不遮挡底栏。测试与截图输出到忽略的 artifacts/，不保存过程记录。
