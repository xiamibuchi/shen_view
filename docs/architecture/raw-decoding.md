# RAW 解码

## 主图与缩略图

主图及邻图预载统一从传感器显影，避免预载成为主图时带入相机 JPEG 的不同曝光。
缩略图优先使用最大可用内嵌预览，缺失、损坏或方向、颜色信息不适用时回退显影。
预览尺寸足够不代表曝光一致，不能仅按分辨率决定主图是否跳过显影。

JPEG 预览保留编码数据和 ICC，由 Flutter 按目标尺寸解码；RGB8 预览后台处理方向与编码。
几何和拍摄信息查询不解包传感器。主图与允许小预览的缩略图使用不同缓存键，
首帧还会检查实际尺寸，避免损坏容器的尺寸声明绕过限制。

## 曝光与缩放

SDR 和 HDR 共用基于 RGB 直方图白点的曝光归一化，抑制极少数高光对估计的影响。
空帧和近黑帧不拉伸，已达到白点的图不压暗；曝光应用于 SDR 曲线和 HDR 未裁切浮点值。
RAW 不套用通用 Reinhard，也不按文件名或相机型号做亮度特判。

输出保持比例，连续缩放合并精度请求，升级分辨率期间保留已显示画面。
SDR 与 HDR 输出、源文件、传感器和内嵌预览各有上限，并受共享预算约束；
100% 视图可能使用预算内显影尺寸，LibRaw 参数不代表整个应用内存上限。
