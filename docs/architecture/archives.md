# 压缩包实现

ZIP/CBZ、RAR/CBR、7Z/CB7、TAR/CBT 通过 ArchiveService.open 建立 ArchiveSession，
由随包 viewer_archive 辅助进程调用 7-Zip 原生引擎。打开时先读条目目录，
显示和预载时按条目编号读取到受限磁盘缓存，同名条目不会覆盖。

Windows 需要 viewer_archive.exe 和相邻 7z.dll，macOS 对应 viewer_archive 和 7z.so。
7z.exe / 7zz 仅用于开发样本，不随 Windows 发行包打包；用户无需另装 7-Zip。

## 打开与容器生命周期

- 新目标首图准备成功后才提交容器；取消、空包和打开失败保留原内容。
- 图片以逻辑来源和条目编号标识，解码前按需取得文件租约。显示结束和资源释放后归还租约。
- 内嵌包按需进入，返回祖先时释放离开容器的资源；嵌套深度受限。
- 普通包可恢复阅读进度；密码包和敏感内层内容不写内部阅读历史。

只读操作、目录层级、排序与换包行为见 [目录导航](../guide/folder-navigation.md)。

## 密码与私有缓存

密码由应用对话框收集，仅通过 stdin 传给 helper，不写命令行、配置或日志。
错误密码可重试或取消。密码包与衍生内容使用会话私有目录，活动租约释放后清理，
异常退出的私有残留在后续维护时清理。

普通缓存可以限额保留；私有缓存不跨会话复用。清理不删除仍被显示或解码使用的文件。

## 固实包

同一固实会话将实际请求短暂合并，共用一次 SDK Extract。
双页切换同时准备两个目标，全部命中缓存时不启动提取。单个消费者取消不影响其他消费者，
全部取消或关闭容器时终止 worker，后续需要时重开。

冷读可按预取偏好保存同固实块、目标之前的附近图片，不请求目标之后的条目。
必需输出与可选输出分别限额。
未知块不推测归组；RAR/RAR5 缺块编号时只使用 SDK 明确的逐文件固实依赖标记。

必需输出先获得空间，可选项不足时跳过。未实现跨命令解压字典检查点，
未命中的远距离冷跳仍可能从固实块起点重建字典。

## 磁盘与资源限制

普通磁盘缓存按容量、条目数与期限淘汰，设置可调整保留策略并手动清理。
输出流逐项及合计限额，写入唯一临时文件，校验成功后提交；失败回滚。
跨进程维护锁和活动文件租约共同保护缓存，解压维护可能使其他窗口等待。

条目路径、输出大小、解压工作量、超时、取消和源文件版本均受检查。
主图及预加载继续使用共享调度与内存预算，见 [资源管理](resources.md)。

## 验证边界

CBZ/CBR/CB7 图片样本验证实际 codec 像素；RAR5 的现有二进制条目样本不代表 RAR5 图片画质实测。
样本及生成方法见 [归档测试输入](../../apps/viewer/testdata/archives/README.md) 和
[漫画样本](../../apps/viewer/testdata/archives/README.md#synthetic-cb7-image-fixtures)。

读取能力与系统文件关联分别验收。macOS 随包构建和运行、完整低配置矩阵、
长期多窗口峰值和冷暖 P50/P95 仍需专项验证。执行入口见 [验证说明](../development/validation.md)。

引擎版本和商业分发义务见 [压缩包许可](../release/archive-licensing.md)，
原生协议与构建见 [helper 说明](../../native/archive_helper/README.md)，
预算与期限以 [磁盘缓存](../../apps/viewer/lib/src/application/archive_disk_cache.dart) 为准。
