# 调度、预加载与缓存

## 主图优先

所有解码共享调度和内存预算，按需求优先级、距离与入队顺序执行。
可见双页都属于前台，辅助工作有独立配额；原生前台保留通道不会扩大外层总并发。
相同资源共享请求，新的前台消费者会提升优先级，离开后按剩余消费者重新确定。

Windows WIC 和 macOS Image I/O 都接收请求身份、优先级、距离与取消信号。
排队取消会移除任务，执行中在阶段间检查；系统解码调用可能需要等返回后才能停止。
实际工作结束并释放资源后才归还执行计数和预算。

## 资源压力

辅助任务为前台保留在途预算，大型编码源可传路径并返回有界预览，减少整文件读入。
取消和临时容量不足不触发兼容后端重试；资源恢复后允许继续请求，保留已显示画面。
失焦和持续压力会减少推测工作，恢复使用迟滞，避免频繁升降档。
预算覆盖输出及主要转换缓冲，不是整个进程 RSS 或 GPU 内存硬上限。

## 预载与缓存

缩略图和阅读主图分别规划。关闭不可见缩略图预加载仍加载可见项；
隐藏胶片栏冻结最后范围，已有计划继续渐进完成，切换集合才撤销旧需求。
滚动稳定后逐步派发，资源不足时收缩或暂停，失败记录有界并允许重试。

阅读预载按模式、方向与距离选择附近页，双页保留完整对开，连续阅读围绕实际可见范围扩展。
较远已有缓存与预留容量分开统计，预留不分配空位图；持续受压后退为按需。
预载范围只决定启动与取消哪些后台任务。成功解码的主图继续交给字节有界的 LRU，
不因离开附近范围立即删除；集合切换、文件失效和资源压力仍主动清理。
缩略图优先使用已缓存的 SDR 图像，需要从较大的缓存图生成时只保留缩小后的副本，
避免胶片栏长期固定整张主图。无可用兜底时，才复用 HDR 源帧及进行中的解码。
HDR 源帧按文件版本复用，取消单个消费者不会中断其他消费者；其常驻字节从
原有图像缓存份额中扣除，与解码在途预算分开统计，不提高总预算。
Dolby helper 的设备可跨文件复用，但单帧原始像素仍按解码任务计入预算，
取消确认前不会释放预留；内存压力和服务卸载可清理 helper 的 GPU 状态。
