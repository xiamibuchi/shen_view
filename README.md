# ShenView

> Your pictures, in focus.

English · [简体中文](README.zh-CN.md)

ShenView is a desktop image viewer for local pictures, folders and comics. Browse photo collections, read long images and open comics directly from archives.

## Features

- **Browse folders comfortably.** Directory navigation, recursive browsing, natural sorting, a grid overview and a thumbnail filmstrip.
- **Read your way.** Single-page, two-page, long-image and continuous reading modes, with flexible image fitting and slideshows.
- **Open comics in archives.** View images in ZIP, CBZ, RAR and CBR files without manually extracting them.
- **Explore animations.** Frame-by-frame viewing and playback controls.
- **Inspect image details.** Color picking, image information and HDR support.
- **View comfortably.** Light and dark themes, with fullscreen viewing.

## Availability

ShenView is in development. Official downloads are not yet available; see [development setup](docs/development/getting-started.md) to build from source.

| Platform | Status |
| --- | --- |
| Windows | Windows 10 version 2004 or later, x64. |
| macOS | In development; validation on Mac hardware is pending. |
| Linux | Not currently supported. |
