# 神羊看图 · ShenView

> 把目光，留给图片。

[English](README.md) · 简体中文

神羊看图（ShenView）是一款用于浏览本地图片、文件夹与漫画的桌面看图工具。可以浏览照片集、阅读长图，也可以直接打开压缩包中的漫画。

## 功能

- **顺手浏览文件夹**：目录导航、递归浏览、自然排序、网格总览与底部胶片栏。
- **选择查看方式**：单页、双页、长图与连续阅读，搭配独立的尺寸适配和自动播放。
- **直接阅读压缩包**：浏览 ZIP、CBZ、RAR、CBR 中的图片，无需事先手动解压。
- **细看动图**：逐帧查看与播放控制。
- **查看图片细节**：颜色拾取、图片信息与 HDR 支持。
- **舒适查看**：深浅主题，全屏浏览。
